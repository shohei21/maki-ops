## 1. ミッション・ビジョン

### ミッション

> **「裏アカOL・まき」を通じて、日常の孤独や甘えたい気持ちに共感してくれる人のための"居場所"を作る。色気より先に人間味で惹きつけ、長く愛されるキャラクターとして収益化する。**

### ビジョン（6ヶ月後のゴール）

| 指標 | 目標値 |
|---|---|
| Xフォロワー数 | **5,000人** |
| note月間売上 | **100,000円以上** |
| note有料購入者数（累計） | **200人以上** |
| エンゲージメント率（X） | **平均3〜5%** |
| コアファン（常連）数 | **50〜100人** |

**理想の状態：**
「まき」を知った人が「この子の日常が気になってフォローし続けてしまう」状態を作り、Xで共感→noteで課金というパスが自動的に機能している。まきに課金することが「ファンとしての自然な行動」になっている。

## 7. 差別化戦略

### 他の裏アカOLと「まき」が違う3つのこと

#### ① 「色気より先に人間味」戦略

```
一般的な裏アカOL：
写真 → フォロー → 課金

まきの戦略：
共感・感情 → 人間味 → 色気が加わる → 「この子が好き」という感情 → 課金
```

**多くの裏アカは「見た目のよさ」で集客し、飽きられやすい。**
まきは「この子のことが気になる」という感情的なつながりを先に作る。
**結果として離脱率が低く、長期的なファンが育ちやすい。**

#### ② 「続きが気になる」設計

| 仕掛け | 内容 |
|---|---|
| 連続ストーリー | 「会社の歳上の先輩の話」を週1で更新。続きが気になってフォローを外せない |
| キャラの成長 | 「裏アカ始めたばかりの初々しさ」→「徐々に大胆になる」という変化を設計済み |
| 未解決の謎 | 父の話・恋愛への恐怖・歳上好きの理由…全部「答え」を急いで出さない |

#### ③ 「ファンが参加できる」設計

| 参加型企画 | 効果 |
|---|---|
| シチュエーション投票 | ファンが「自分が選んだコンテンツ」を購入する。離脱率が下がる |
| 歳上さんへの質問 | フォロワーが「まきに話しかけられた」体験。返信が増え、アルゴリズムにも有利 |
| 常連さん制度 | 「まきのコミュニティの一員」という帰属感。SNSを離れにくくなる |

---

### 長期的なファンを作るための仕掛け

#### 感情の積み重ね設計

```
Week 1〜4   ：共感（OLあるある・孤独・疲れ）でフォローしてもらう
Month 1〜2  ：親しみ（日常・弱さ・照れ）で「好き」を作る
Month 2〜3  ：色気（グラビア・大胆な写真）を「まきらしさ」として出す
Month 3〜   ：ストーリー（連続投稿・成長）で「次が気になる」を維持
Month 4〜   ：コミュニティ（常連さん・メンバーシップ）で「ここが居場所」化
```

#### 「まきが成長する物語」を見せる

> 裏アカ開設初日から6ヶ月後まで、**まきが徐々に大胆になり、ファンと関係が深まる物語**そのものをコンテンツにする。
> ファンは「まきの成長を見守っている」感覚を持つ。これが最強の離脱防止になる。

```
07:30〜07:45
□ 起床後にXを開き、昨夜の反応を確認（いいね・RT・返信）
□ 返信が来ていたら2〜3件返す（毎日返すことが信頼につながる）
□ 朝投稿：「今日も仕事か〜」「月曜つら」など1本（共感系・30秒で書ける）
```

**朝投稿の狙い：** 朝の通勤時間帯（7〜9時）はXのエンゲージメントが高い。短い一言でもいいので毎朝投稿する。

#### 昼（5〜10分）

```
12:00〜12:10
□ ランチタイムに1投稿（「ひとりでご飯食べてる」「今日のコンビニ飯」など）
□ 前の投稿への返信があれば返す
□ 他のアカウントの投稿にいいね・リプライ（相互エンゲージメント）
```

**昼投稿の狙い：** 会社員フォロワーのランチタイム閲覧に乗る。
