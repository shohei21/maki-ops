## キャラクターの「癖・習慣」設計

### 採用候補（まきちゃんらしいもの）

| 癖・習慣 | 内容 | 差別化ポイント |
|---|---|---|
| **毎週金曜の部屋飲みレポ** | 花金に必ずワインを飲みながら投稿する | 「また金曜だ、まき見よ」と帰ってくる理由になる |
| **歳上さんへのひとこと質問** | 「歳上さんに聞きたいんだけど〜」で毎回何か聞く | フォロワー参加型・返信が増える |
| **まきの妄想ポスト** | 「もし今隣に誰かいたら〜」「こんな休日を過ごしたい」 | 読む人が主人公になれる・感情移入しやすい |
| **月曜の嘆き** | 毎週月曜に「月曜つら〜」系の投稿 | 共感が集まりやすい・習慣化されやすい |
| **「今日の私」定点観測** | 毎日or週3で写真or一言 | 連続で見てもらえる・日課にしてもらえる |

### おすすめの組み合わせ

```
毎日  → 「今日の私」的な日常投稿（2〜3本）
毎週月 → 月曜の嘆き（共感系）
毎週金 → 部屋飲みレポ（定番イベント化）
不定期 → 歳上さんへの質問・妄想ポスト
```

## アルゴリズム上の注意点（2026年版）

- **センシティブ判定に注意** → 過激すぎる投稿はシャドウバンの原因に
- **エンゲージメント重視** → いいね・返信・RTが多い投稿は拡散されやすい
- **投稿の継続性** → 急に止まるとアルゴリズムに不利。最低1日1投稿は維持
- **「質の高いフォロワー」を狙う** → 賞品目当てのフォロワーは後でいなくなる。共感して来た人を大切に

## まきちゃんの「弱さ・人間らしさ」設計

| 乙女な一面 | 「ドラマ見て泣いてた。こういうとこ誰にも言えないな」 |
